=> ENCAPSULATION:- 
   wrapping up of data & member functions in a single unit called class. 
   And restricting direct access to the data by using access specifiers such as private, protected, and public.

=> One-line definition (remember this):-
   Encapsulation = data hiding + controlled access in a class

=> Quick check:
   If a class has:-

   ✔ private data
   ✔ public getter/setter (controlled access in a class)

   → You are using encapsulation.
